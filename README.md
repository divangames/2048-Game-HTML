# 2048 Game with Leaderboard
![image](https://github.com/user-attachments/assets/1fdcc3e5-ef04-49b0-973e-70cd854291c2)


## Описание
Это веб-приложение представляет собой классическую игру 2048 с возможностью сохранения результатов игроков в таблице рекордов. Игра написана на HTML, CSS и JavaScript и использует Node.js для серверной части, которая хранит рекорды в JSON-файле.

## Особенности
• Современный дизайн с использованием шрифта "Montserrat Alternates". </br>
• Плавные анимации при перемещении блоков.</br>
• Сохранение и отображение таблицы рекордов.</br>
• Возможность отправки своего результата после завершения игры.</br>

## Установка и запуск
### Предварительные требования
• [Node.js](https://nodejs.org/en?spm=5aebb161.7946a69d.0.0.dc4ac921YPXEtR). (версия 14 или выше)</br>
### Шаги по установке
#### 1. Клонирование репозитория:
``` js
sh
 git clone https://github.com/divangames/2048-game.git
cd 2048-game
 ```
#### 2. Установка зависимостей:
``` js
sh
npm install
```
#### 3. Запуск сервера:
``` js
sh
node server.js
```
#### 4. Открытие игры в браузере:
Откройте ваш браузер и перейдите по адресу:
``` http://localhost:3000 ```

### Использование
1. Нажмите кнопку "New Game" для начала новой игры.</br>
2. Играйте, двигая блоки влево, вправо, вверх и вниз с помощью клавиш со стрелками.</br>
3. После завершения игры введите свой никнейм и нажмите "Submit Record", чтобы сохранить результат.</br>
4. Таблица рекордов будет автоматически обновлена.</br>
